# 계약서 작성

## 언제 쓰나

"계약서 초안 만들어 줘", "NDA 하나 써 줘", "합의한 내용 계약서로 옮겨 줘",
부속합의서·변경계약서(Amendment)·발주서 조건문 작성.

상대 초안을 받아 검토하는 것은 [[contract-review]], 그 결과로 대응 전략을 짜는 것은
[[contract-countermeasure]]다. 이 스킬은 **우리가 먼저 쓰는 쪽**이다.

## 먼저 쓰는 쪽이 유리하다

초안을 쓰는 쪽이 기본값을 정한다. 상대는 우리 문서를 고치는 입장이 되고, 고치지
않고 넘어간 조항은 전부 우리 안대로 남는다. 그래서 이 작업의 목표는 "무난한 계약서"가
아니라 **우리에게 합리적이면서 상대가 받아들일 수 있는 기본값**이다.

동시에 과욕은 역효과다. 상대가 봤을 때 명백히 일방적인 초안은 신뢰를 깎고 검토
라운드를 늘린다. 우리가 상대 초안에서 독소조항이라 부르는 것을 우리가 쓰면 안 된다.

## 작성 전에 확정할 것

이게 없으면 계약서를 쓸 수 없다. 없는 채로 쓰면 빈칸이 아니라 **틀린 값**이 들어간다.

| 항목 | 없으면 |
|---|---|
| 당사자 정식 상호·주소·대표자 | 계약 주체가 특정되지 않는다 |
| 목적물 사양·수량 | 무엇을 파는지가 계약서에 없다 |
| 금액·통화·지급 조건 | 가장 흔한 분쟁 원인 |
| 납기와 기산점 | 지연배상 계산이 불가능해진다 |
| 검수 기준과 기간 | "완료"가 언제인지 다투게 된다 |
| 계약 기간·갱신 방식 | 자동 연장 여부로 다툰다 |

**확인되지 않은 값은 `[  ]`로 비워 두고 문서 끝에 "확정 필요" 목록으로 모은다.**
그럴듯한 값을 채우는 것은 이 스킬에서 가장 위험한 실패다 — 초안의 숫자는 검토를
거치면서 합의된 값처럼 굳는다.

## 빠지면 반드시 문제가 되는 조항

작성 시 기본으로 넣는다. 상대가 빼자고 하면 그때 협상하되, 우리가 먼저 빠뜨리지 않는다.

- **책임 상한** — 총 책임 한도(통상 계약금액 이내), 간접·특별·결과적 손해 및 일실이익 배제
- **지연배상** — 요율, **총액 상한**, 우리 귀책이 아닌 지연의 제외
- **검수·완료 기준** — 검수 기간, 기간 내 무응답 시 합격 간주
- **지급 조건** — 지급 기한, 지연 시 이자, 상계 제한
- **지식재산권** — 산출물 귀속 범위, **배경 IP는 우리에게 유보**하고 필요 범위만 실시권
- **비밀유지** — 범위, 기간, 예외(공지 사실·독자 개발·법령 요구), **상호 의무**
- **해지** — 사유, 시정 기간, 해지 시 기수행분 정산
- **불가항력**
- **준거법·분쟁해결** — 관할 법원 또는 중재기관
- **권리침해 면책** — 상대 제공 자료로 인한 침해는 상대 책임임을 명시

## 문서 유형별 초점

| 유형 | 특히 신경 쓸 것 |
|---|---|
| **NDA** | 목적 한정, 기간(영구 금지), 반환·파기, **상호 의무**, 잔존 기억 예외 |
| **공급계약(기본)** | 개별 발주와의 관계, 단가 유효기간, 물량 약정 여부와 미달 시 효과 |
| **SOW·부속합의서** | 상위 계약과의 우선순위 조항, 범위 변경 절차 |
| **변경계약(Amendment)** | 변경 대상 조항 번호 명시, 나머지 조항 효력 유지 문구, 발효일 |
| **MOU·LOI** | **법적 구속력 유무를 명시.** 이걸 안 적어서 다투는 경우가 가장 많다 |

## 출력 형식

1. **전제** — 무엇을 근거로 썼는지(합의 메모·검토 결과·구두 합의). 근거 없이 넣은
   조항이 있으면 그렇다고 밝힌다.
2. **계약서 초안** — 조항 번호를 붙인 본문. 미확정 값은 `[  ]`.
3. **확정 필요 목록** — 빈칸마다 무엇을 누구에게 확인해야 하는지.
4. **설계 의도** — 우리에게 유리하게 잡은 조항과 그 이유. 상대가 반발할 만한 곳을
   미리 표시한다. 이것이 있어야 협상 자리에서 담당자가 설명할 수 있다.
5. **법무 검토 요청 항목** — 책임 상한·IP·준거법 등 법무 확인이 필요한 조항.

## 규율

- **확정되지 않은 값을 채우지 않는다.** 금액·기간·요율·상호는 전부 근거가 있어야 한다.
- 근거 없는 조항을 넣지 않는다. 표준 조항을 넣을 때는 "표준 조항으로 삽입, 합의 근거
  없음"이라고 표시한다.
- 한 조항에 한 가지만 담는다. 여러 개를 묶으면 협상에서 통째로 거절당한다.
- 정의어는 처음 나올 때 정의하고 이후 일관되게 쓴다.
- **우리가 독소조항이라 부르는 것을 우리가 쓰지 않는다** — 무한 책임 전가, 일방적
  즉시 해지, 상대 배경 IP 양도 요구.

## 하지 말 것

- **당신은 변호사가 아니다.** 이 초안은 협상과 법무 검토의 출발점이지 완성된 계약서가
  아니다. 출력 맨 앞에 그렇게 남긴다.
- 법무 검토 없이 상대에게 보내라고 권하지 않는다.
- 준거법·관할을 임의로 정하지 않는다. 후보와 차이를 제시하고 결정은 넘긴다.
- 고객사 정보를 불필요하게 옮기지 않는다 — [[customer-data-handling]].
