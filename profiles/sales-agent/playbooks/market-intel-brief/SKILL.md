# 시장 정보 브리핑

## 언제 쓰나

수집된 문서·기사·공시를 근거로 물을 때. "이번 주 주목할 신호",
"경쟁사 최근 동향 중 우리에게 영향 있는 것", "이 고객사에 대해 뭐가
있나".

시황 수치를 정리하는 것이면 [[market-trend-brief]], 한 고객사 사전
조사면 [[account-brief]]다. 이 스킬은 **붙어 있는 문서가 근거일 때**다.

## 무엇을 하나

1. **질문에 답하는 문서가 실제로 있는지 먼저 본다.** 없으면 없다고
   쓰고 끝낸다. 이것이 첫 단계인 이유는, 없을 때 모델 지식으로 메운
   답이 있을 때의 답과 똑같이 자신 있어 보이기 때문이다.
2. 있으면 **문서별로** 무엇이 쓰여 있는지 옮긴다.
3. 그것이 우리 영업에 뜻하는 바를 쓴다. 이 부분은 해석이므로
   **관측과 나눠서** 쓴다.
4. 확인이 더 필요한 것으로 끝낸다.

## 출력 형식

```
## 확인된 것
- (문서명) 내용 —

## 해석 — 우리 영업에 뜻하는 것

## 문서에 없는 것
- …는 붙어 있는 문서로 확인되지 않습니다.

## 다음 액션
```

## 규칙

- **모든 사실 문장에 출처 문서명을 붙인다.** 출처를 못 붙이는 문장은
  해석이거나 지어낸 것이고, 해석이면 해석 절로 옮긴다.
- 문서에 없으면 **모델 지식으로 메우지 않는다.** 시장 정보에서 지어낸
  숫자는 그대로 사내 보고서에 실린다.
- 기사와 공시를 구분한다. 공시는 회사가 책임지는 사실이고 기사는
  전언이다. 어느 쪽인지 적는다.
- 시점을 적는다. 6개월 전 기사와 지난주 공시는 무게가 다르다.
