# 샘플 계약서

`docs/examples.md` 를 만들 때 쓴 입력입니다. 실재하지 않는 회사·조건으로 지어낸
문서이고, 워크스페이스를 처음 열어 보거나 플레이북을 고친 뒤 결과가 달라졌는지
비교할 때 쓰라고 남겨 둡니다.

| 파일 | 무엇 |
|---|---|
| `표준공급계약서_2026.docx` | 우리 표준. **선례 코퍼스에 넣고 시작하세요** — 이게 있어야 검토가 "관행상" 대신 실제 수치를 근거로 댑니다. |
| `공급계약서_한빛_불리.docx` | 상대 초안. 지연배상 무상한, 무기한 검수·품질보증, 배경 IP 귀속, 사유 불문 해지, 일방 관할. 단가표 포함(표 파싱 확인용). |

## 해보기

1. **계약서 분석** 워크스페이스에서 `표준공급계약서_2026.docx` 를 올리고 첨부 칩의
   "선례로 추가" 를 누릅니다.
2. `공급계약서_한빛_불리.docx` 를 올리고 "을 관점에서 검토해 줘" 라고 합니다.
3. **협상 대책** 에서 계약금액과 목표 마진을 함께 주면 최종선이 계산됩니다.
   주지 않으면 `근거 필요` 로 남는데, 그게 맞는 동작입니다.
4. **계약서 작성** 에서 합의 내용을 부속합의서로 옮깁니다.
